# Security Considerations

## Website Setup

Our website only uses simple HTML and CSS. We do not have a server or a database, so it is very safe from attacks.

## No User Forms

There are no places for users to type information on our site. Because of this, bad users cannot put dangerous code (like **SQL Injection** or **XSS**) into our pages.

## Safe Links

We checked all the links that go to other websites to make sure they are set up safely.

## Future Plans

If we add forms for users to fill out later, we will need to:

- Check the data carefully
- Use a secure connection (**HTTPS**) to keep user information safe online
